# מפת צירי זמן — מסמך תכנון

## בקצרה

- מפת עולם + ציר זמן עם זום: בוחרים שכבות אירועים, צוללים בזמן, רואים מה קרה איפה.
- אתר סטטי בלבד (GitHub Pages): בלי שרת, בלי מסד נתונים, בלי התחברות.
- המטרה: מוצר עובד מהר ככל האפשר, ואז פידבק.
- מקור הבריף: הפתק "Timelines App" ב-Second Brain. האפליקציה הישנה לא מחייבת.

## צורת המימוש (מאושר)

- **Skill / MCP — לא מספיק:** המוצר הוא חוויה חזותית לבני אדם בדפדפן.
- **UI ייעודי — נדרש:** המפה וציר הזמן האינטראקטיביים הם המוצר.
- **שרת מרוחק — לא נדרש:** נתונים בקבצים בריפו, אין משתמשים, שיתוף דרך URL.
- לעתיד (לא עכשיו): skill שעוזר לכתוב קבצי שכבה.

## סטאק (מאושר — גישה A)

- Vite + TypeScript + React.
- MapLibre GL JS למפה (WebGL, pinch חלק, מעגלים בק"מ, מניעת התנגשות תוויות).
- רקע: גבולות מדינות Natural Earth שנארזים עם האתר — בלי מפתח API.
- ציר זמן: רכיב משלנו על d3-scale + d3-zoom.
- Vitest ליחידות, Playwright לבדיקות דפדפן.
- היטל Mercator (MapLibre לא תומכת בשווה-שטח).

## מודל נתונים

- קובץ לכל שכבה: `data/layers/<id>.json`.
- שכבה: `id`, `name`, `creator`, `color?`, `events`.
- אירוע: `id`, `name`, `description?`, `lat`, `lng`, `radiusKm?`, `start`, `end?`.
- תאריך: `{ year, month?, day? }`; שנה שלילית = לפנה"ס; שנת 0 לא חוקית.
- פנימית: שנה אסטרונומית (1 לפנה"ס = 0) + שבר שנה, כדי שהחשבון יהיה רציף.
- אין `end` → אירוע נקודתי (ביום/חודש/שנה לפי הדיוק של `start`).
- בדיקת סכמה בטסטים וב-build: קובץ שבור מכשיל CI, לא את האתר.
- נתוני התחלה: שתי השכבות מ"Timelines App - Sample data", רדיוס מומר לק"מ בהערכה.

## ציר הזמן

- רצועה אופקית בתחתית; גרירה = הזזה בזמן, pinch/גלגלת = זום בזמן.
- קנה מידה מתאים לזום: אלפי שנים → מאות → עשורים → שנים → חודשים.
- על הרצועה: פס לכל אירוע בצבע השכבה, כדי לראות איפה יש תוכן.
- מצב התחלתי: הטווח המלא של השכבות שנבחרו, ציר רציף (בלי כיווץ פערים).
- תוויות: `N לפנה"ס` / `N לספירה`; אין שנת 0.

## המפה

- מוצג כל אירוע שחופף לחלון הנראה של הציר.
- עיגול חצי-שקוף ברדיוס אמיתי בק"מ; בלי רדיוס → נקודה בגודל קבוע.
- תווית שם מעל; תוויות מתנגשות מוסתרות.
- צבע לכל שכבה (מהקובץ, או מפלטה קבועה).

## פריסה ואינטראקציה

- ממשק בעברית, RTL, סגנון מינימלי שהמפה במרכזו.
- טלפון (mobile-first, 375×667): כותרת דקה + כפתור "שכבות" → bottom sheet עם checkbox לכל שכבה.
- דסקטופ: השכבות בפאנל צד קבוע.
- כמה שכבות במקביל; היוצר מוצג כקרדיט של השכבה.
- מצב פתיחה: השכבה הראשונה טעונה.
- הקשה על עיגול → כרטיס פרטים: שם, טווח תאריכים, תיאור, ✕.
- הכרטיס נסגר אם האירוע יוצא מהחלון.
- אין אירועים בחלון → "אין אירועים בתקופה הזו" + קפיצה לאירוע הקרוב.

## URL

- דוגמה: `?layers=ancient,wars&t=-500,200&map=41.9,12.5,4`.
- כל שינוי מעדכן את ה-URL (replaceState); פתיחה משחזרת.
- ערכים לא חוקיים ב-URL → מתעלמים מהם ונופלים לברירת מחדל.

## בדיקות ופריסה

- Vitest: מודל תאריכים, סכמה, מסנן חלון, קידוד/פענוח URL.
- Playwright ב-375×667: טעינה, זום בציר משנה את המפה, הקשה על אירוע, שחזור מ-URL.
- GitHub Actions: CI על כל push; פריסה ל-GitHub Pages מ-main.

## מחוץ לגרסה הראשונה

- PWA / אופליין, פוליגונים וקווים, מצב כהה, גלובוס, skill לכתיבת שכבות, ליטוש עיצובי.

## סדר הבנייה

1. מפה + שתי השכבות + ציר עם זום שמסנן את המפה — באוויר ב-GitHub Pages.
2. בורר שכבות וצבעים.
3. כרטיס פרטים + מצב ריק.
4. URL.
